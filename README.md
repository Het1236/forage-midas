# JPMorgan Chase & Co — Software Engineering Job Simulation

This repository contains the project I built during the Software Engineering Job Simulation with JPMorgan Chase & Co. through Forage.

### ✅ Key Features Implemented
- Spring Boot microservice setup
- Kafka message queue integration
- H2 in-memory database with CRUD operations
- REST API integration with external service
- REST controllers for data exposure

### 🛠️ Technologies Used
- Java 17
- Spring Boot
- Apache Kafka
- H2 Database
- REST APIs
- Maven

### 🎯 Learning Focus
Industrial software engineering practices, distributed systems fundamentals, microservices communication, and backend application architecture.
